# Embun - Drinking Water E-Commerce Website

Embun is a responsive e-commerce website for a drinking water business, developed as both a school assignment and a real-world project to support my father's business. Built with HTML, CSS, JavaScript, and Bootstrap 5, this website provides a clean and user-friendly interface for showcasing bottled drinking water products and making it easier for customers to explore available products.

The website features an interactive product catalog, product detail modals, a shopping cart sidebar, a promotional carousel, and an FAQ section. This project allows me to apply my web development skills to a practical business use case while gaining hands-on experience in building responsive and interactive websites.

**Key Features**

* Responsive website layout
* Interactive promotional carousel
* Product catalog with product details
* Shopping cart sidebar using Offcanvas
* Product detail modal
* FAQ section with Accordion
* Bootstrap Icons integration
* Modern and clean user interface

**Tech Stack**

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Bootstrap Icons

**Project Purpose**

This project was created to fulfill a school assignment while also serving as an initial step toward building a digital storefront for my father's drinking water business.

*Built as a learning project with a real-world business purpose.*
